# Churn Prediction — End-to-End MLOps System

**🔗 Live demo:** [prediction-services-l4xh.onrender.com/docs](https://prediction-services-l4xh.onrender.com/docs)
> Hosted on Render's free tier — if idle, the first request can take ~50 seconds to wake up.

A production-style ML system: not just a trained model, but the full
lifecycle around it — versioned data, tracked experiments, a model
registry, a validated serving API, containerization, CI/CD, and drift
monitoring.

**Dataset:** IBM Telco Customer Churn (7,043 customers, 21 features).
Predicts whether a customer will churn from account/service attributes.
